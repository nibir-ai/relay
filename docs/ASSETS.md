# Custom UI assets

## Documentation guides

Four original SVG illustrations in `docs/assets/` explain integration, native execution, authentication and response exports. They are authored diagrams with example routes, not captured product screens. Colors follow Relay's terminal palette. Every SVG includes accessible title/description text; commands remain copyable in Markdown. PNG exports provide portable embeds for GitHub and package documentation.

Run `python scripts/docs_assets.py` to regenerate the SVG masters from their editable source. PNG files are browser-rendered exports of those masters; refresh them when changing the drawings. No font installation is required.

- `fastapi-quickstart.svg`: install, mount, open.
- `fastapi-native.svg`: existing app, same port, real handlers.
- `endpoint-auth.svg`: shared token or endpoint override, then Authorize.
- `response-export.svg`: execute, inspect, choose Relay or JSON.

## Product artwork

Generated using the built-in image-generation tool in generation mode, visually inspected, and converted to WebP. These are decorative artwork, not fabricated API response screenshots.

- `apps/web/public/assets/relay-signal.webp`: prompt direction — premium studio sculpture, interlocking brushed graphite and restrained chartreuse signal ribbons, smoky glass connector, near-black background, no text. Retained in the bundle for compatibility; not displayed in the current testing interface.
- `apps/web/public/assets/relay-key.webp`: prompt direction — premium credential key sculpture, dark capsule and smoky glass details, restrained chartreuse key teeth, near-black studio background, no text. Retained in the bundle for compatibility; not displayed in the current testing interface.
- `apps/web/public/relay-mark.svg`: lowercase r with a baseline cursor, used as a transparent favicon with browser light/dark colors. Its master geometry and the custom outlined wordmark are generated by `scripts/brand_assets.py`. Seven reusable SVG variants live in `apps/web/public/brand/`; the app uses symbol/wordmark alpha masters colored by the selected theme. See [brand usage](BRAND.md).
- `docs/brand/relay-identity-concept.png`: documentation-only identity board, generated with the built-in image tool; exact prompt in the sibling `.prompt.txt` and embedded metadata. SVG exports define production geometry.

JetBrains Mono variable font is bundled via `@fontsource-variable/jetbrains-mono`; there is no font CDN or remote image dependency.
